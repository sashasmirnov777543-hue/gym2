GYMKEEPER OFFLINE 1.1 — HUAWEI WATCH GT 5 PRO

Добавлено:
1. Три системных уведомления после окончания отдыха — для тройной вибрации часов.
2. Кнопка теста: Настройки → Проверить тройную вибрацию через 3 секунды.
3. Прямое подключение к трансляции пульса Huawei Watch по Bluetooth LE.
4. Текущий пульс и автоматический средний пульс в кардио.

Как обновить существующий репозиторий:
1. Распаковать ZIP.
2. Заменить содержимое папки GymKeeper-Android в локальном репозитории новой папкой GymKeeper-Android.
3. GitHub Desktop → Commit → Push origin.
4. Actions автоматически соберёт новый APK.
5. В старой версии сначала скачать свежую JSON-копию.
6. Удалить старую версию 1.0 (её временная подпись не совместима с обновлением).
7. Установить новый app-debug.apk 1.1 и восстановить JSON.
8. Все последующие версии можно будет ставить поверх 1.1: в проект добавлен постоянный ключ подписи.

После установки:
- разрешить GymKeeper уведомления и поиск Bluetooth-устройств;
- Huawei Health → Устройства → GT 5 Pro → Уведомления → включить GymKeeper;
- для пульса включить на часах «Трансляция пульса», затем в кардио нажать «Подключить часы».
