# GymKeeper Offline 3.0

- Встроена финальная программа H2 → V9: 9 + 13 восьмидневных циклов, 88 тренировочных дней.
- RMref = 115 кг; ручное обновление только на контрольных точках.
- Старая программа архивируется, история сессий и подходов сохраняется.
- Удалены из активной программы AMRAP, board press, pin press и старый автоматический пересчёт ТМ.
- Добавлены паузный жим, Spoto, RPE/RIR-ограничители и тестовая тройка.
- Кардио только Z1/Z2, без HIIT и финишеров.
- Разминочные пункты отображаются отдельно и не требуют записи подходов.
- Исправлены длинные инструкции, карточки упражнений и группировка циклов.
- При восстановлении старой JSON-копии программа автоматически мигрирует до v3.
