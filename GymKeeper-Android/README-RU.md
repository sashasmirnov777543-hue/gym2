# GymKeeper Offline 3.0 — Realme 8 / Android 13

Полностью автономное персональное приложение. Разрешения INTERNET нет; Vercel, Neon и сайт не используются.

## Обновление репозитория

1. Сделайте JSON-копию в текущем GymKeeper.
2. Распакуйте ZIP 2.0.
3. Замените в локальном репозитории папку `GymKeeper-Android` новой.
4. Корневой `.github/workflows/build-apk.yml` замените содержимым файла `GymKeeper-Android/WORKFLOW-FOR-NESTED-REPO.yml`.
5. GitHub Desktop → Commit → Push origin.
6. Actions выполнит тесты и соберёт `GymKeeper-offline-2.0-android13`.
7. Скачайте артефакт, распакуйте и установите `app-debug.apk`.

Если на телефоне уже установлена версия 1.1 с постоянной подписью — ставьте 2.0 поверх неё. Если установлена первоначальная 1.0 с временной подписью — сначала экспортируйте JSON, удалите 1.0, установите 2.0 и восстановите JSON.

## Первый запуск

Разрешите:
- уведомления — для тройной вибрации Huawei Watch;
- устройства поблизости — для BLE-пульса.

По умолчанию включён системный вход: используется PIN/отпечаток экрана блокировки телефона. Его можно отключить в Настройках GymKeeper.

## Huawei Watch GT 5 Pro

### Пульс
1. На часах запустите тренировку.
2. В настройках тренировки включите «Трансляция пульса» / HR Data Broadcasts.
3. В кардио GymKeeper нажмите «Подключить часы».

### Тройная вибрация
1. Huawei Health → Устройства → GT 5 Pro → Уведомления.
2. Разрешите уведомления GymKeeper.
3. GymKeeper → Настройки → Проверить тройную вибрацию.

## Резервные копии

Настройки → Скачать JSON-копию. Файл сохраняется в `Загрузки/GymKeeper`. Перед удалением приложения всегда делайте свежую копию.

Подробный список изменений: `CHANGELOG-2.0.md`.


## Обновление 3.0

Версия 3.0 содержит финальную программу H2 → V9 и автоматически переносит существующие локальные данные без удаления истории. Перед установкой всё равно сделайте JSON-копию. Точка входа после обновления: V9, цикл 4, B2.
