# GymKeeper Offline для Realme 8 / Android 13

Это отдельное автономное приложение. Оно не открывает веб-сайт и не подключается к Vercel, Neon, GitHub или другим сервисам. В AndroidManifest намеренно отсутствует разрешение `INTERNET`.

## Что перенесено

- программы V9 и H2 из копии от 10.07.2026;
- вся история тренировок, подходов и кардио;
- TM по макроциклам и история изменений;
- запись веса, повторов, RIR, скорости и мёртвой точки;
- readiness с зелёным/жёлтым/оранжевым/красным уровнем;
- автоматический мини-тейпер;
- AMRAP: Epley → 0,90 → округление 2,5 кг;
- рекомендации нагрузки по RIR;
- миорепсы с отдыхом 20 секунд и лимитом 4 мини-серии;
- кардио-таймер по реальному времени и talk-test;
- прямой BLE-пульс с Huawei Watch GT 5 Pro в режиме «Трансляция пульса»;
- автоматический расчёт среднего пульса за кардио;
- три системных уведомления после отдыха для тройной вибрации часов;
- история, статистика и офлайн-справочник техники;
- совместимый импорт/экспорт JSON.

## Самый простой способ получить APK

1. Создайте новый пустой репозиторий GitHub.
2. Распакуйте этот ZIP и скопируйте **содержимое папки** `GymKeeper-Android` в репозиторий.
3. Сделайте Commit и Push через GitHub Desktop.
4. На странице репозитория откройте вкладку **Actions** → **Build offline APK**.
5. Откройте последний успешный запуск и скачайте артефакт `GymKeeper-offline-android13`.
6. Распакуйте его: внутри будет `app-debug.apk`.
7. Передайте APK на Realme 8, откройте файл и разрешите установку из этого источника.

GitHub нужен только один раз для компиляции APK. Установленное приложение не использует GitHub и работает без интернета.

## Сборка через Android Studio

1. Установите Android Studio на компьютер.
2. `Open` → выберите папку `GymKeeper-Android`.
3. Дождитесь Gradle Sync. Требуется Android SDK 35 и JDK 17.
4. `Build` → `Build APK(s)`.
5. APK: `app/build/outputs/apk/debug/app-debug.apk`.

## Huawei Watch GT 5 Pro

### Тройная вибрация таймера

1. При первом запуске разрешите GymKeeper отправлять уведомления.
2. В Huawei Health откройте: Устройства → HUAWEI WATCH GT 5 Pro → Уведомления.
3. Включите GymKeeper в списке приложений.
4. В GymKeeper откройте Настройки → «Проверить тройную вибрацию через 3 секунды».

### Пульс во время кардио

1. На часах запустите тренировку и включите «Трансляция пульса» / HR Data Broadcasts в настройках тренировки.
2. На телефоне включите Bluetooth.
3. В кардио GymKeeper нажмите «Подключить часы».
4. Разрешите поиск Bluetooth-устройств.
5. Текущий и средний пульс будут заполняться автоматически.

Передача использует стандартный Bluetooth Heart Rate Service и работает без интернета.

## Первый запуск и данные

В приложение уже встроена переданная копия `gymkeeper-backup-2026-07-10.json`. Она загружается только при первом запуске. После этого все изменения хранятся в локальном хранилище приложения.

Рекомендуется регулярно открывать **Настройки → Скачать JSON-копию**. Файл сохраняется в `Загрузки/GymKeeper`.

При удалении приложения локальные данные могут быть удалены. Перед удалением обязательно сделайте JSON-копию.

## Обновление приложения

При установке новой версии APK поверх старой локальная база сохраняется, если не менять `applicationId` и не удалять приложение. Встроенная начальная копия не перезаписывает уже существующие данные.

## Безопасность

- разрешение INTERNET отсутствует;
- внешние HTTP/HTTPS-запросы блокируются WebView;
- данные не покидают телефон;
- пароль не нужен: доступ защищается блокировкой самого телефона;
- резервная копия JSON не зашифрована — храните её в личной папке.

## Важное обновление с версии 1.0 на 1.1

Первая APK была подписана временным ключом GitHub Actions. Поэтому перед переходом на 1.1:

1. В старом GymKeeper скачайте свежую JSON-копию.
2. Удалите старое приложение.
3. Установите APK версии 1.1.
4. В версии 1.1 восстановите свежую JSON-копию.

Начиная с версии 1.1 в проект включён постоянный личный ключ подписи. Последующие обновления можно устанавливать поверх 1.1 без удаления и без потери данных. Не удаляйте файл `app/gymkeeper-offline.jks`.
