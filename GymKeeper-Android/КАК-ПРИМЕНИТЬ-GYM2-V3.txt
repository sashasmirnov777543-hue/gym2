GYMKEEPER OFFLINE 3.0 — ФИНАЛЬНАЯ H2 → V9

ПЕРЕД НАЧАЛОМ
1. В установленном приложении откройте Настройки.
2. Скачайте свежую JSON-копию.
3. Убедитесь, что репозиторий gym2 обновлён через Fetch origin.

КАК ПРИМЕНИТЬ
1. Распакуйте архив в корень локального репозитория gym2.
   Рядом с файлами должна быть папка GymKeeper-Android.
2. Запустите APPLY-GYM2-V3.bat.
3. Дождитесь сообщения «ГОТОВО. Проверки пройдены».
4. Удалите из корня три служебных файла:
   - APPLY-GYM2-V3.bat
   - apply-gym2-v3.mjs
   - program-v3.js
   Не удаляйте program-v3.js внутри GymKeeper-Android/app/src/main/assets — это файл приложения.
5. GitHub Desktop → Summary: «GymKeeper Offline 3.0 — финальная H2 V9».
6. Commit to main → Push origin.
7. GitHub → Actions → последний Build GymKeeper Offline 3.0.
8. После зелёной галочки скачайте артефакт GymKeeper-offline-3.0-android13.
9. Распакуйте и установите app-debug.apk поверх текущей версии.

ЧТО ИЗМЕНЕНО
- 9 циклов H2 и 13 циклов V9, 88 тренировочных дней, 479 пунктов упражнений.
- RMref 115 кг вместо AMRAP-пересчёта ТМ.
- Точка входа: V9, цикл 4 «Мини-делоуд», B2.
- Нет AMRAP, board press и pin press в активной программе.
- Паузный жим, Spoto, RPE/RIR-ограничители, контрольные точки и тестовая тройка.
- Кардио Z1/Z2 без HIIT.
- Разминка не требует записи подходов.
- Старые циклы архивируются; история сессий и подходов сохраняется.
- При восстановлении старой JSON-копии миграция v3 запускается автоматически.
- Обновлено оформление длинных инструкций и карточек упражнений.

ВАЖНО
- При первом запуске миграция выполняется локально на телефоне один раз.
- Интернет и база Neon не используются.
- Если Android откажется устанавливать APK из-за подписи, сначала НЕ удаляйте старое приложение без JSON-копии.
